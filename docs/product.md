# Product overview

University Match helps students find higher-education programs aligned with
their academic background, budget, location preferences, and funding needs.

## Initial user journey

1. Create or update an academic and preference profile.
2. Request a ranked set of potentially suitable programs.
3. Review eligibility, estimated affordability, and the sources behind each
   result.
4. Save programs for later comparison.

## Product principles

- Explain recommendations and distinguish verified data from estimates.
- Do not present a match as an admission guarantee or financial-aid promise.
- Make important data limitations visible to students.
